| 1   | `.navigationTitle("Alex")` at line 40 is called on a bare `VStack` with no enclosing `NavigationStack` or `NavigationSplitView`. The modifier is silently ignored: no navigation bar renders.                                                                                                                      | NavigationStack contract          | P0       | Wrap the root view in `NavigationStack { ... }` so `.navigationTitle` and any `.toolbar` items are honored.                                                                                                         |
| 2   | `.padding(.bottom, 34)` at line 37 hardcodes the home indicator clearance. This value is wrong on every device other than the one it was designed on (iPhone 14 Pro). Devices with no home indicator receive excess padding; older notch devices or iPad receive too little or misaligned insets.                  | Safe area insets                  | P0       | Remove the hardcoded padding. Use `.safeAreaInset(edge: .bottom)` for the compose bar, or wrap the compose `HStack` in a view that uses `.ignoresSafeArea(.keyboard)` and lets the system manage bottom insets.     |
| 3   | The reply thread "expand" button at line 174 is only reachable when the thread is collapsed (`else` branch). When expanded, the button disappears entirely and the expanded thread has no collapse affordance. The user is permanently locked into the expanded state with no way to collapse without app restart. | One-directional interactive state | P0       | Move the toggle button outside the `if/else` split so it renders in both states, changing its label between "N replies" and "Hide replies".                                                                         |
| 4   | `Color.blue` used as bubble background for outgoing messages at line 64. For iMessage-style bubbles use `Color(uiColor: .systemBlue)` which adapts, or define a design-system token.                            |
