## Top-line verdict

**REWORK.**

This is a stock-SwiftUI conversion of a tutorial — the SKILL.md reflex list in order: `systemBackground` composer, `Color.blue` bubbles with `.cornerRadius(10)`, `.gray` metadata, hardcoded `.padding(.bottom, 34)` for the home indicator, zero materials, zero `ButtonStyle`, zero haptics, zero `.accessibilityLabel`, zero animations, zero Dynamic Type strategy, and no Asset Catalog tokens. Every quadrant of the rubric fails in the same way: trained defaults went to the canvas untouched. The bar is not "it runs" — the bar is a messaging surface that reads as native iOS 26 chat, and this does not. Polish cannot paper over the missing token system, the missing interaction states, and the missing accessibility layer. Start from a design brief, then rebuild.

## Why this verdict, not "polish-first"

Polish-first is defensible when the skeleton is right and the details are thin. Here the skeleton is the problem: no token system, no navigation structure, no materials, no interaction states, no accessibility. Fixing 43 findings is a rewrite — attempting to polish each line preserves the original mistake (reactive modifier pile). The craft.md loop exists specifically to prevent this outcome: shape → reference → build. This file skipped shape and reference. Starting over with a brief produces a shorter file and a better one.
