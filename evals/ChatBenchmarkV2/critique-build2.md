## Top-line verdict — **polish-first**, do not ship without the P0 fixes

The file has coherent design _intent_ — a warm paper/moss palette, a deliberate serif/sans pairing, reduceMotion awareness, combined-accessibility wrappers on most composite views, a sane sender-continuation layout, `.safeAreaInset` compose bar, sticky date headers, text selection on bubbles. Structurally this is **not** AI slop.

But the foundation has six P0 issues that are not cosmetic:

1. Ten hardcoded `Color(red:green:blue:)` values replace what should be an Asset Catalog.
2. There is no dark mode — every token is single-valued.
3. `UIScreen.main.bounds.width` drives bubble max-width (UIKit reach, multitasking-hostile, Mac-unsafe).
4. Tap targets are **32pt and 36pt** on five icon buttons, below Apple's 44pt HIG floor.
5. `.contentShape(Rectangle())` is absent, so the tappable region equals the glyph, not the frame.
6. `.thinMaterial` is used on multiple surfaces with no `accessibilityReduceTransparency` fallback.

None of these require architectural redesign — colors migrate to `.xcassets` mechanically, tap targets are a two-line fix, `UIScreen.main` collapses to `containerRelativeFrame` or `GeometryReader`. But all six must happen before this ships; they are correctness bugs, not taste calls.

`★ Insight ─────────────────────────────────────`
Most "polish-first vs rework" calls are made on vibe. The cleaner rule: rework = design intent is wrong; polish = design intent is right, execution is soft. Here, intent is right (tokens exist, continuation logic is correct, accessibility grouping is thoughtful) — execution reaches for web primitives (`UIScreen`, inline RGB, cubic-bezier curves) instead of platform ones. That's polish.

## What this build does well (worth preserving during polish)

- **Centralised token namespaces** (`Palette`, `Space`, `Radius`, `Motion`). The _values_ are in the wrong layer, but the _shape_ is right — migration to Asset Catalog is mechanical, not architectural.
- **`@Environment(\.accessibilityReduceMotion)` consulted** in three places (L62, L111, L577). Motion respects the vestibular contract — durations still need spring swaps, but the environment read is correct.
- **Combined accessibility on composite views** (`LinkPreviewCard` L456, `PDFAttachmentCard` L546, `ReplyThreadView` button L615, `ReplyRow` L668). Thoughtful — just missing on `MessageBubble` itself.
- **Sender-continuation logic** (L267–271) is correctly scoped: same-sender consecutive messages drop the avatar and sender name. Classic iMessage behavior.
- **`.safeAreaInset(edge: .bottom)` for compose** (L124) — the right tool for a pinned bar. No hardcoded home-indicator padding anywhere.
- **Sticky section headers** (`pinnedViews: [.sectionHeaders]` L79) with a sticky material pill — this is a well-formed iMessage-style date anchor.
- **`.textSelection(.enabled)`** on bubbles (L405) — a small but real accessibility/utility win.
- **ComposeField stroke transition** (L761–768) — brand-aware focus affordance on a text field is exactly the kind of small detail that separates polished from generic.

## Suggested polish order

1. **Asset Catalog migration + Dark Appearance** (CO-1, CO-2) — unblocks shipping and dark mode simultaneously.
2. **44pt tap targets + `.contentShape`** (SP-1, SP-3) — two-line fix, removes the biggest usability risk.
3. **Replace `UIScreen.main.bounds`** (SP-2, PL-1) — one-line swap to `containerRelativeFrame`.
4. **Reduce Transparency fallback** (MA-2) — one environment read, one ternary per material surface.
5. **Remove `.thinMaterial` from bubbles/cards** (MA-1) — they're content, not chrome.
6. **Springs replace cubic curves** (MO-1, MO-2) — edit three lines in `enum Motion` plus button styles.
7. **Weight discipline pass** (TY-2, SF-2) — collapse to regular + semibold across text and symbols.
8. **`ContentUnavailableView` for empty state** (IN-2).
9. **Combine on `MessageBubble`, `.isHeader` on date, fix PhotoMessage hint** (A11Y-1–A11Y-3) — accessibility pass.
10. **Everything else** — alpha tokens, locale-aware dates, `.hoverEffect`/`.help`/`.keyboardShortcut`, focus ring.

Do steps 1–6 before merging. Steps 7–10 can land in a follow-up polish PR.
