## Top-line verdict — **polish-first**

The file is materially above the SwiftUI default reflex. Decisions trace to named reference rules in inline comments (sticky headers via `pinnedViews` instead of `List`, `Spacer(minLength:)` as bubble-width clamp, `.safeAreaInset` for the compose bar, `.glassEffect()` + `GlassEffectContainer`, hierarchical SF Symbols throughout, Reduce Motion branches on every animation, semantic typography end to end). Materials are picked, not stacked. Spring physics are correct.

Two P0s and a cluster of P1s prevent ship: both compose-bar buttons are 40 × 40 (below the 44pt tap floor), the photo bubble is fixed-pixel and won't survive Dynamic Type, the empty conversation has no `ContentUnavailableView`, and three single-line labels lack `.minimumScaleFactor` and will silently truncate at large text sizes. Plain-styled buttons with custom backgrounds skip the press contract.

None of these are structural — they are mechanical, bounded fixes. After they land, this is a defensible reference build.

## What's working — keep doing this

- `LazyVStack(pinnedViews: [.sectionHeaders])` instead of `List` — sticky date dividers without inheriting `List`'s separator and selection chrome. Picks the right primitive for the visual intent.
- `Spacer(minLength: 56)` as the bubble-width constraint instead of reading `UIScreen` — survives Split View, Stage Manager, Dynamic Type cleanly. Genuinely good thinking.
- `.safeAreaInset(edge: .bottom)` for the compose bar — exactly what navigation.md prescribes.
- `GlassEffectContainer` + `.glassEffect()` on the compose bar, with the inner text field on `.quaternary` (a hierarchical fill) — material discipline is correct.
- `.thinMaterial` capsule for the floating date header instead of a `Divider()` — depth via material, not via a hairline.
- `reduceMotion` is checked on every animation, with `.opacity` substituted for spatial transitions. The asymmetric reply-list transition (move + opacity insertion, opacity-only removal) is a textbook implementation.
- `.sensoryFeedback(.success, trigger: sendPulse)` is the right semantic cluster for an outcome signal, fired through an `Int` trigger.
- `monospacedDigit()` on every numeric — timestamps, file size, reply count, date header — so digits don't reflow.
- `.symbolRenderingMode(.hierarchical)` is consistent across every SF Symbol on the surface. One mode, one set.
- Four previews including Dark, Dynamic Type Accessibility2, and a keyboard-open stand-in. The craft.md preview discipline is honored.

## Recommended fix order

1. **P0 (1 commit):** Expand both compose-bar buttons to a 44pt tap floor — visual stays 40pt, hit region grows via `.frame(minWidth:minHeight:).contentShape(Rectangle())`. Findings 1, 2.
2. **P1 (1 commit):** Add the empty-state `ContentUnavailableView`, fix the `TextBubble` accessibility label to include the timestamp, and add `.minimumScaleFactor` to the three single-line labels. Findings 5, 8, 9, 10, 11.
3. **P1 (1 commit):** Extract a `CapsuleAffordanceButtonStyle` and apply it to the plus and disclosure buttons. Findings 6, 7.
4. **P1 (1 commit):** De-pixel the photo bubble — `@ScaledMetric` for the 56pt icon and a max-width-only frame for the surface. Findings 3, 4.
5. **P2 sweep:** Snap off-scale spacing values, demote the `.bold` send arrow to `.semibold`, drop the unused `reduceTransparency` env, and either token-ize or document the accent opacity ladder. Findings 12, 13, 14, 15, 16, 17.
6. **P2 platform:** Decide whether this view ever roots a Mac/iPad target. If yes, add hover effects + `NavigationSplitView` consideration. Findings 20, 21.
7. **P3 polish:** `let messages`, swap stringly-typed scroll anchor for `ScrollPosition`, fix the "Them" VoiceOver fallback. Findings 22, 23, 25.

After step 4 the file ships. Steps 5–7 are debt to retire when the surface leaves benchmark scope.
